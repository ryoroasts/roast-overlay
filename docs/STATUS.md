## このセッションで直した2件(Session 2 完了後)

### 1. 同じプロファイルの `.klog` が区別できなかった

```
修正前: ninjaturtle.kpro / ninjaturtle.kpro
修正後: log0028 (ninjaturtle) / log0029 (ninjaturtle)
```

`.klog` の表示名を **ログのファイル名を主、プロファイル名を従**に変更(`src/lib/klog.ts`)。
同じプロファイルを Level 違いで焼いて比べるのは中心的な使い方
(記事04 = ninjaturtle を Lv1.5 / Lv2.0)なので、実用上の不具合だった。

### 3. 🟡 保留: フェーズの可視化

**「メイラードなど3フェーズを初心者に分かりやすく」という要望が出ているが、保留。**

現状フェーズは**表の数字でしか存在しない**。グラフ上は Dry end / First crack / Roast end の
マーカーだけで、「その間がメイラード」が目で見えない。

検討した2案:

| | 案 | 問題 |
|---|---|---|
| a | グラフ背景に3色の帯を敷く | **複数ログを重ねると帯も複数になり境界がずれて濁る** |
| b | フェーズ表に積み上げ横棒を1列足す | 複数ログでも壊れないが、直感性は a に劣る |

→ **複数重ねたときに分かりづらくなる**という理由で保留(2026-08-14 本人判断)。
再開するなら SPEC の拡張として扱う(現 SPEC の「やらないことリスト」には無い機能)。
